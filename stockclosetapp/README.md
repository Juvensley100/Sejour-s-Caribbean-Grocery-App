# Stock Closet

Stock Closet is an inventory management app for retail teams that need fast product lookup, accurate stock counts, and simple item maintenance in one place.

## Vibe Coding Stack

- Next.js
- Supabase
- Antigravity

## How to Run

```bash
npm run dev
```

## Project Overview

This app supports common retail workflows such as:

- searching for a product by name, SKU, or category
- checking quantity and price quickly at the register
- adding new inventory items
- editing item details when stock changes
- removing discontinued products
